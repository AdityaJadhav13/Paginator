# ADR-018: Gate-driven roadmap (G0–G7)

**Status:** ACCEPTED. 2026-10-07. Supersedes the P0–P5 phase plan in `13`, revision 1.

## Decision
- Progress is measured only by real-world gates G0–G7, defined in `13`, each with entry criteria, success criteria, evidence, artefacts, an owner, the meaning of failure, and what stops if it fails.
- Development that serves a later gate is not started in earnest until the earlier gates it depends on have passed.
- Exception: deliberately parallel research, such as the pilot questionnaire, observation and corpus work.

## Rationale
All three previous codebases advanced through many internal phases without proving the core hypothesis: a real Marathi page, typeset correctly, accepted by a real press. The phase plan in v2 repeated the pattern by putting SaaS breadth before the first printed page.
